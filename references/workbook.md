# 검증 워크북 (build_workbook.py) — 산출물 서식과 구조 정의

보고서를 엑셀에 그대로 옮기고 검증식을 **살아 있는 수식**으로 심은 재수행 조서다.
지적사항 목록(build_report.py)과 합쳐 한 파일로 낸다. 검토자는 셀에서 무엇을 어떻게 확인했는지 본다.

참고 원형: 2026-08 반기검토보고서용 사내 AI Footing 워크북.
원형에서 고친 점 두 가지 — ① 원형은 합계 자리에 `=SUM` 을 넣어 검증이 항상 TRUE 였다. 여기서는
**보고서에 적힌 합계를 값으로 두고** 검증셀이 Σ항목과 비교한다. ② 원형은 보고서 내부 정합성만 봤다.
여기서는 조서(정산표) 대사 열과 전기 보고서 대사 열을 붙인다.

## 시트 구성

| 시트 | 내용 |
|---|---|
| 총괄표 | 시트별 링크 · 푸팅/산식/크로스/조서/전기 오류 건수(수식) · 구조 미인식 · 조서 미매칭 · 지적 S/A/B/C 건수 · 핵심 결론 |
| 지적사항 · 숫자대사 · 검증완료 | build_report.py 와 동일 (03_findings.json 이 있을 때) |
| BS · PL · MC · CE · CF | 재무제표 전문 + `조서 값/차이` + `전기보고서/차이` 열, 아래에 ■ 푸팅 검증 · ■ 산식 검증 · ■ 구조 미인식 · ■ 크로스 참조 |
| 1 … N | 주석 번호별. 문단은 텍스트, 표는 값. 합계행 아래 `└ 푸팅검증`, 변동표는 오른쪽에 `└ 행검증` 열 |
| S1 … Sn | pptx 보고서일 때 슬라이드별 (deal). 구성은 주석 시트와 같다 |
| 서술검산 | deal 보고서 본문 문장 속 수치를 표 값으로 재계산 (structure.json `claims`) |

검증셀은 `=IF(ABS(차이)<허용오차, TRUE, 차이)`, 연노랑 바탕. 숫자가 보이면 오류이고 조건부서식으로 붉게 칠해진다.
총괄표 건수는 `SUMPRODUCT(--ISNUMBER(검증범위))` 로 센다.

## 기계가 스스로 하는 것

- **재무제표 계층** — dsd 의 `ALEVEL` 로 소계 = Σ직계 항목. 소계가 음수이고 항목이 양수면(현금흐름표 차감항목) 부호 반전으로 인식하고 검증행에 적는다.
- **표준 산식** — BS 자산총계·부채총계·자본총계·부채와자본총계 / PL 매출총이익·영업이익·법인세차감전·순이익 / MC·CF 는 "직전 소계 + 사이 항목" 누적.
- **재무제표 간 크로스** — CF 순이익 = PL, CF 기말현금 = BS 현금, CE 기말 총계 = BS 자본총계, CE 순이익 = PL.
- **주석 표 합계** — `합계·소계·계·총계·차감계·기말잔액·장부금액…` 행을 찾아 `Σ행 / 직전소계+Σ행 / Σ소계 / 소계−소계` 네 해석 중 맞아떨어지는 것을 골라 수식으로 남기고 어느 해석인지 검증행에 적는다. 비율·일수·단가 열은 제외.
- **변동표 행검증** — 헤더에 기초…기말이 있으면 기말 = Σ열. 표시 부호 그대로 더해 안 맞고 감소성 열(처분·회수·상환…)을 빼면 맞으면 그 산식을 쓴다.
- **조서 대사** — 라벨 정규화(공백·번호·로마숫자·(주석n)·손실↔이익 표기 통일) + 순서 근접 매칭 + 별칭표(정부보조금↔국고보조금 등). 못 찾으면 `미매칭` 으로 남긴다.
- 반올림 단위(천원 등) 표는 허용오차 ±1 (`tol_rounded` 1.5). 원 단위는 ±0. 천원 표 ↔ 원 본문 크로스는 ±5,000.

## 모델이 정하는 것 — `04_structure.json`

전부 선택 항목이다. 콘솔의 `구조 미인식` · `조서 미매칭` · `차이 상세` 를 보고 채운다.

```json
{
  "tol": 0.5, "tol_rounded": 1.5, "auto_rollforward": true,
  "rules": {"PL": [{"target": "매출총이익", "expr": "매출액 - 매출원가"}]},
  "skip": {"PL": ["주당손익"]},
  "note_rules": [{"note": "6", "table": 3, "cols": ["기초잔액","취득","처분","감가상각비"], "result": "기말잔액"}],
  "note_skip": [{"note": "18", "table": 4}],
  "xrefs": [{"label": "주석3 재고자산 평가액 = BS 재고자산",
             "from": {"note": "3", "table": 1, "row": "합계", "col": "평가액 당기"},
             "to":   {"sheet": "BS", "row": "재고자산", "period": 0}, "scale": 1000, "tol": 5000}],
  "wp": {"BS": {"file": "정산표.xlsx", "sheet": "BS", "label_col": "A", "first_row": 3,
                "periods": [["B","C"],["D","E"]],
                "sign_neg": ["대손충당금","감가상각누계액","국고보조금"],
                "map": {"현금및현금성자산": ["당좌예금","제예금","기타제예금"]}}},
  "claims": [{"loc": "슬라이드 4", "text": "Series B 자금소진율 103.21%", "claim": 103.21, "unit": "%",
              "expr": "{a}/{b}*100",
              "refs": {"a": {"note": "S4", "table": 1, "row": "Series B", "col": "합계"},
                       "b": {"note": "S4", "table": 1, "row": "Series B", "col": "투자금액"}}, "tol": 0.005}]
}
```

- 참조(`from`/`to`/`refs`)는 두 형식: 재무제표 `{"sheet":"BS","row":"라벨|행번호","period":0}`,
  표 `{"note":"3","table":1,"row":"라벨|행번호","col":"헤더 단어들|열번호"}`. `col` 은 헤더 여러 줄을 이어 붙인 문자열에 단어가 모두 들어 있으면 매칭.
- `wp.periods` 는 기간별 열 묶음. 세부·합계 두 열이면 둘 다 적는다 (뒤 열 우선).
- `sign_neg` 는 조서에서 양수로 적힌 차감계정을 음수로 뒤집는다. `map` 은 보고서 한 줄 = 조서 여러 줄 합.
- `claims.expr` 의 `{키}` 자리에 셀 주소가 들어간다. 파이썬으로도 같은 식을 계산해 콘솔에 낸다.

## 명령

```
python {skill}/scripts/build_workbook.py _footing/{run}/01_report.json -o "풋팅결과_{보고서명}.xlsx"
    --findings _footing/{run}/03_findings.json      # 지적사항 시트
    --structure _footing/{run}/04_structure.json    # 위 구조 정의
    --prev _footing/{run}/01_prev.json              # 전기 보고서 extract 결과 (전기 열 대사)
```

콘솔에 시트별 `오류/검증수` 표와 `차이 상세` 가 찍힌다. 파이썬 재계산 기준이며, 엑셀에서 열면 같은 수가 총괄표에 나와야 한다.
`--prev` 에 당기 파일을 그대로 넣으면 전기 열 vs 당기 열 비교가 되어 전부 차이로 뜬다 (코드 경로 확인용).
