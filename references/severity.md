# 중요도 판정 기준

발행을 막을 것인가로 가른다. "고치면 좋다"와 "안 고치면 안 된다"를 섞지 않는다.

## S — 발행 전 필수 수정

보고서를 이대로 내보내면 **틀린 정보가 나가거나, 결론이 근거로 뒷받침되지 않는** 경우.

- 숫자가 틀렸다 (합계 불일치, 조서와 금액 상이, 전기 수치 미갱신)
- placeholder·미완성 표시가 남아 있다 (`~~~`, TBD, `xx일`, 빈 증빙목록)
- 보고서가 서술한 설명이 **금액적으로 성립하지 않는다** — 차액을 계산해 제시할 수 있으면 무조건 S
- 조서에 미결(확인필요) 항목이 남은 채 "이상 없음"으로 결론지었다
- 금액적으로 중요한 거래에 필수 검토 절차가 누락됐다 (이해관계인 여부, 특수관계자 판정)
- 자금·수량 추적이 중간에 끊겨 있다 (계좌 간 이체 증빙 부재)

S급은 **건수가 적어야 한다.** 열 건이 넘으면 등급 인플레를 의심한다.

## A — 내용 보강·확인 필요

틀리지는 않았으나 **읽는 사람이 판단할 근거가 부족한** 경우.

- 보고서와 조서의 값이 서로 다른 정의를 쓴다 (투자일자 = 납입일인가 회계 인식일인가)
- 근거 조서 자체가 없거나 한쪽 시리즈·기간만 있다
- 통상 기재하는 항목이 빠졌다 (산식 정의, 기간, 단위, 절차·범위, 설립일, 주식수)
- 집계 대상 범위가 조서에 명시되지 않았다 (계좌 혼재, 표본 기준)
- 계약·규정상 요건과 실제의 부합 여부에 대한 의견이 없다

## B — 표 형식·레이아웃

인쇄물 품질 문제. 대부분 `format_audit.py` 가 기계적으로 잡는다.

- 셀 텍스트가 폭을 넘거나 여유 0.15cm 미만이라 줄바꿈 위험
- 같은 표·같은 행에서 글꼴·크기 혼재, 같은 열에서 정렬 혼재
- 도형·표 좌표가 0.01~0.15cm 어긋남, 나란한 표의 하단선 불일치
- 합계행 강조 누락, 합계행 빈 칸
- 헤더 박스 폭 제각각, 단위 표기가 열 제목 자리를 차지

## C — 문구·오타·띄어쓰기

- 이중 공백, 줄 끝 공백, 탭 정렬
- 같은 말의 띄어쓰기 혼용 (발생 여부 / 발생여부)
- 회사명·용어 표기 혼용 (○○㈜ / ○○ 주식회사)
- 인용한 절 제목이 실제 제목과 다름
- 비문, 불필요한 보조사, 중복 어미

## 등급을 낮추는 사유

**전기 서명본 답습**은 등급을 낮추는 근거가 된다. 전기 보고서에도 같은 표기가 있으면 그 사실을 근거란에 적고, 단독 판단 대신 "답습 여부 판단 필요"로 넘긴다. 다만 **숫자 오류는 답습이어도 S급이다.**

## 등급을 올리는 사유

금액적 중요성. 같은 성격의 지적이라도 집행총액의 절반을 차지하는 거래에 걸리면 한 등급 올린다. 근거란에 비중을 숫자로 적는다.
