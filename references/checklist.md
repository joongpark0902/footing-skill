# 공통 점검 항목 — 보고서 종류 불문

`format_audit.py` 와 `tie_out.py` 가 자동으로 잡는 항목은 ⚙ 로 표시했다. 나머지는 모델이 본다.

## 1. 숫자

- ⚙ 표 내부 합산 — 행합·열합·총계
- ⚙ 표간 대사 — 같은 항목이 여러 표에 나올 때 값이 같은가
- ⚙ 조서 대사 — 보고서 수치가 조서 어느 셀·어느 구간 합에서 나오는가
- ⚙ 역방향 커버리지 — 조서에는 있는데 보고서에 없는 수치
- 비율·소진율·구성비 재계산 (정의가 보고서에 있는가부터)
- 전기·전분기 비교수치가 전기 서명본과 일치하는가
- 단위 환산 (천원·백만원 표기와 실제 자릿수)
- 반올림 관행 일관성 (합계가 개별 합과 1 차이 나는 경우 처리 방식)

## 2. 결론과 근거

- 조서에 **미결 플래그**(확인필요·TBD·검토중·pending)가 남아 있는가 → 건수·금액·비중을 세라
- 보고서가 "~때문이다"라고 쓴 설명을 숫자로 검산했는가
- 결론 문장의 한정 범위가 실제 수행 절차와 맞는가
- 수행하지 않은 절차를 수행한 것처럼 읽히지 않는가
- 증빙 목록이 실제 입수 증빙과 일치하는가

## 3. 표 형식

- ⚙ 셀 텍스트 폭 대 열 폭 (여유 0.15cm 미만은 위험)
- ⚙ 같은 표·행 안의 글꼴·크기 혼재
- ⚙ 같은 열 안의 정렬 혼재
- ⚙ 합계행 강조·빈 칸
- 열 폭 배분 (한쪽은 넘치고 한쪽은 남는가)
- 셀 여백 (우측정렬 금액이 테두리에 붙지 않는가, 0.15~0.20cm 권장)
- 단위 표기 위치 (열 제목 자리를 차지하고 있지 않은가)
- 각주 번호가 표 안에 참조 표시로 걸려 있는가

## 4. 레이아웃

- ⚙ 도형·표 좌표 미세 어긋남
- ⚙ 나란한 표의 하단선 불일치
- 섹션 헤더 박스 폭 통일
- 표지 글꼴이 본문과 다른 경우 대체글꼴 위험
- 페이지 번호 연속성, 표지 제외 여부
- 여백 균형 (한쪽만 비어 있지 않은가)

## 5. 문구

- ⚙ 이중 공백·줄 끝 공백·탭 정렬
- ⚙ placeholder (`~~~` TBD TODO `xx`)
- ⚙ 같은 말의 띄어쓰기 혼용
- 회사명·법인명 표기 통일 (약칭을 쓸 거면 첫 등장에서 정의)
- 인용한 절 제목이 실제 제목과 일치하는가
- 용어 혼용 (사용목적/사용용도, 발생 여부/발생여부)
- 비문 — 같은 조사·어미 중복, 주술 불일치
- 보고서일과 서명일 일치
- 곡선 따옴표·전각/반각 혼용

## 6. 조서 자체

- 집계 대상 범위가 조서에 명시되어 있는가 (계좌·기간·표본)
- 조서 요약값과 상세 합계가 일치하는가
- 상세와 원천 rawdata가 전수 일치하는가
- 한쪽 시리즈·기간만 조서가 있고 나머지는 없는가
